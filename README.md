# um terminal simples
usa comandos padrão do shell Android.

## pacotes online:

instalar asm
instalar node
instalar clang

## instalar pacote customizado:
instalar /caminho/absoluto/pacote.zip

## estrutura de pacote:
bin
usr (casos especificos)
etc (casos especificos)
lib

## compatibilidade testada:
Android 8 até Android 15.
